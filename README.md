# Hustle Bee – Creative Portfolio Website

A responsive, single-page portfolio website template for presenting personal information, skills, selected projects, education, professional experience, and contact details.

> **Note:** The current website uses the sample “Hustle Bee” profile and demonstration content from the Tooplate 2169 Hustle Bee template. Replace the sample text, statistics, project details, education, experience, contact information, and images with your own information before publishing it as a personal portfolio.

## Live Demo

- **GitHub Repository:** https://github.com/suganyadreams7-jpg/Project1
- **Live Website:** Add your deployed website URL here (for example, a GitHub Pages URL).

## Features

- Responsive single-page portfolio layout
- Navigation links to About, Skills, Work, Education, Experience, and Contact sections
- Hero section with introduction and calls to action
- About section with profile image and highlight statistics
- Skills and tools displayed in a visual grid
- Selected projects with descriptions and technology tags
- Education and professional experience cards
- Animated scroll-reveal effects
- Active navigation link highlighting while scrolling
- Mobile navigation menu
- Contact section with contact details and a form layout

## Built With

- **HTML5** – Page structure and content
- **CSS3** – Styling, responsive layouts, transitions, and animations
- **JavaScript (Vanilla)** – Mobile navigation, scroll effects, and active navigation state
- **Google Fonts** – Baloo 2 and Nunito

## Getting Started

No package installation or build tools are required.

### Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/suganyadreams7-jpg/Project1.git
   ```

2. Open the project folder:

   ```bash
   cd Project1
   ```

3. Open `index.html` in your web browser.

You can also use the **Live Server** extension in Visual Studio Code for local development.

## Customization

To make this portfolio your own:

1. Update the name, headline, and introduction in the hero section of `index.html`.
2. Replace the About, Skills, Projects, Education, and Experience content with accurate information.
3. Replace the images in the `images/` folder and update their paths in `index.html`.
4. Update the email address and social profile links in the Contact section.
5. Adjust colors, typography, spacing, and responsive styles in `tooplate-2169-hustle-bee.css`.
6. Update the browser page title and meta description in the `<head>` section of `index.html`.

### Important: Contact Form

The current contact form is a visual front-end layout. The submit button does not send messages by itself. Connect the form to a backend or a form-handling service before using it to receive enquiries.

## Deployment

You can deploy this static website using GitHub Pages:

1. Open the repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose the `master` branch and the `/ (root)` folder.
5. Save the settings and wait for GitHub Pages to publish the site.
6. Copy the published URL into the **Live Demo** section above.
